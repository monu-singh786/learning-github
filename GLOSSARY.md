# GitHub Glossary

## GitHub

GitHub is a website where people store, share, and collaborate on projects.

## Repository

A repository is a project folder on GitHub. It can contain code, notes, documents, images, and history.

## README

A README is the main explanation file for a repository. It tells visitors what the project is about.

## Commit

A commit is a saved change. It helps people understand what changed and when it changed.

## Branch

A branch is a separate place to work on changes before adding them to the main project.

## Pull Request

A pull request is a request to review and merge changes into a project.

## Issue

An issue is a place to report a problem, ask a question, or suggest an improvement.
