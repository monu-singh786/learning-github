# Roadmap

This roadmap shows what I want to learn next in GitHub.

## Stage 1: Basic GitHub Setup

Create a GitHub profile README. Create a public learning repository. Add a clear README file. Practice creating and editing files.

## Stage 2: Project History

Learn what commits are. Write better commit messages. Understand how GitHub shows file history.

## Stage 3: Collaboration

Learn what issues are. Learn what branches are. Learn how pull requests work. Practice reviewing changes.

## Stage 4: Beginner Projects

Create a simple personal website. Create a daily learning log. Create a small notes project. Publish work publicly.

## Stage 5: Confidence

Keep improving repositories, write clearer documentation, and ask others for feedback.
